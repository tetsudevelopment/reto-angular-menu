# ChallengeAngular

Este proyecto fue generado utilizando [Angular CLI](https://github.com/angular/angular-cli) versión 19.2.6.

## Requisitos previos

Antes de comenzar, asegúrate de tener instalados los siguientes programas en tu máquina:

- [Node.js](https://nodejs.org/en/) (Recomendado LTS)
- [npm](https://www.npmjs.com/) (Se instala automáticamente con Node.js)
- [Angular CLI](https://angular.io/cli) (Si no lo tienes instalado globalmente, ejecuta `npm install -g @angular/cli`)

## Clonación del repositorio

1. Clona el repositorio usando Git:

    ```bash
    git clone https://github.com/tetsudevelopment/reto-angular-menu.git
    ```

2. Navega a la carpeta del proyecto:

    ```bash
    cd reto-angular-menu
    ```

## Instalación de dependencias

Antes de iniciar el proyecto, debes instalar las dependencias necesarias. Ejecuta el siguiente comando para instalar los paquetes de npm:

```bash
npm install
```
## Correr el proyecto 

Ahora para correr el proyecto hazlo con: 

```bash
ng serve
```
O con npm

```bash
npm run start
```
